# Bộ gõ Việt - bản đầy đủ (TESC-GV/TESCKEY)

1. Giải nén thư mục này ra Desktop.
2. Bấm đúp `cap-nhat-github.bat`, đăng nhập GitHub bằng tài khoản TESC-GV khi cửa sổ hiện ra.
3. Settings > Pages > Branch main, thư mục /docs > Save. Chờ tab Actions xanh, tải `CaiDat-BoGoViet.exe` ở Releases hoặc trang tải về và cài.

Không dùng GitHub: bấm đúp `build-local.bat` để tự dựng `dist\BoGoViet.exe`.
